# Vault Library — Per-Title Release Record (template)

**Purpose:** one record per title. A title cannot inherit another title's
release permission, format, delivery terms, or rights status. No title is
listed for sale until its record is complete AND Chais approves its price.

Copy this file to `~/workspace/books/releases/<slug>-release-record.md` and
fill it in for each title. Status stays `DRAFT` until every gate below is met.

## Release checklist (all must be YES)

- [ ] Source, author, and date recorded
- [ ] Rights and contributor scope cleared
- [ ] Accessibility checked (text, alt text, transcript where relevant)
- [ ] Delivery defined and access-controlled
- [ ] Price approved by Chais (in writing, per title)
- [ ] Owner release confirmed (explicit, current, for this title and edition)
- [ ] Paddle restricted-content review cleared IN WRITING (metaphysical / spiritual titles)
- [ ] No token/NFT sale, mint, pre-sale, or token-as-reward language (unless a written per-asset Howey attorney analysis clears this specific asset)
