# Templates

Starter templates from Chais Hill's public repos — take them, build on them, make them yours. No repo contents are cloned here; these are links to the public repos themselves. Both repos are public on GitHub under [@chaishillomnitech1](https://github.com/chaishillomnitech1), verified from the workspace repo record (17 Nov 2026 survey).

## [scrollverse-web-app](https://github.com/chaishillomnitech1/scrollverse-web-app)

The ScrollVerse front door — *"The Living Sovereign Digital Ecosystem"*, in its own README's words. The React/Next.js app that carries the books reading routes, the store, the marketplace and the ScrollVerse pages. Its README makes large claims about integrations and commerce; those are the repo's claims, not verified live deployments — scrollverse.co itself is currently down (in preparation). Use the code as a starting point, and verify any integration before relying on it.

## [nextjs-boilerplate](https://github.com/chaishillomnitech1/nextjs-boilerplate)

The ScrollVerse Next.js starter — *"ScrollVerse Ecosystem: God Frequency"*, in its own README's words. A Next.js 15 / React 19 / TypeScript boilerplate for starting a new ScrollVerse-style app. A starter template, not a finished product.
