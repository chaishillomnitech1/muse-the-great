Muse the Great Concierge — Demo

This page shows the concierge widget running in guide mode — the way it behaves on any repo before a backend is connected.

Click the ✦ button at the bottom right and try: “What books can I read?”, “How much is the hoodie?”, “Tell me about the NFTs”, or something it cannot know, like “What will the token be worth?” — and watch how it answers. Every guide-mode answer is labelled “from the repo guide”. It never pretends a live AI is answering.

Drop-in (one line)

Copy the concierge/ folder into the repo, add a config.json from config.example.json, then add this line to the repo’s GitHub Pages site:

<script src="concierge/concierge.js" data-config="concierge/config.json"></script>

Full instructions: README.md in this folder. Design: ../concierge-design.md.
